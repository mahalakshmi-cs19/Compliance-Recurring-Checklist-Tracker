# Compliance & Recurring Checklist Tracker

A web-based system for managing compliance checklists and recurring tasks.

## Problem Statement

Organizations need a simple way to manage recurring compliance activities, track task completion, record notes and evidence, identify overdue tasks, and maintain audit records.

## Objective

The objective of this project is to provide a centralized system for creating checklists, assigning recurring tasks, monitoring completion, and maintaining compliance history.

## Main Features

- Create and manage compliance checklists
- Daily, weekly, and monthly recurring tasks
- Track pending, completed, and overdue tasks
- Add inspection notes and comments
- Upload photo evidence
- View audit history
- Generate reports
- Export compliance data
- User and role management

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git and GitHub

## Project Structure

- `app.py` – Starts the Flask application
- `Routes/` – Handles application routes
- `Services/` – Contains application logic
- `Models/` – Contains data models
- `Templates/` – Frontend HTML pages
- `Static/` – CSS, JavaScript, and other static files
- `tests/` – Project tests

## How to Run

1. Open the project folder in VS Code.
2. Install the required dependencies.
3. Start the Flask application.
4. Open the local server in a web browser.
